# Brand assets and identity

"Gearage" is a **working name**. Nothing outside `src/config/brand.ts`, `messages/*.json` and `docs/` may contain it
(`npm run brand:check` fails CI otherwise). To rename: edit `brand.name`, replace the artwork in `design/brand-source/`,
run `npm run brand:assets`, run the tests.

## Where things live

| What                                                 | Where                                                                      |
| ---------------------------------------------------- | -------------------------------------------------------------------------- |
| Store name per locale, tagline, SEO text, logo paths | `src/config/brand.ts` (typed)                                              |
| Colors (brand orange `#FF5A00`, dark `#0D1114`)      | `src/design/tokens.ts` (generates `src/styles/tokens.css`)                 |
| Contact and social details (editable)                | `StoreSetting` key `contact` (`domain/store-settings.ts`, admin UI in M11) |
| Placeholders in UI text                              | `{brand}` and `{tagline}` in `messages/*.json`, resolved at load time      |

## Logo files

Originals exactly as supplied: `design/brand-source/` (not served; includes the PSDs).
Web files in `public/brand/` are the **same artwork** with only the transparent margins cropped (no pixel changes), generated by
`npm run brand:assets`. Nothing was redrawn.

> Naming trap in the supplied files: **no suffix = light artwork (for dark backgrounds)**; **`-dark` = dark artwork (for light backgrounds)**.
> In `public/brand/` the names say where to use them instead.

| File (`public/brand/`)            | Use                                                                          |
| --------------------------------- | ---------------------------------------------------------------------------- |
| `logo-inline-on-dark.png`         | Header/footer, horizontal, on dark backgrounds (default theme)               |
| `logo-inline-on-light.png`        | Same, on light backgrounds                                                   |
| `logo-stacked-on-dark.png`        | Home hero, auth pages, emails (dark header), on dark backgrounds             |
| `logo-stacked-on-light.png`       | Same, on light backgrounds (invoices, light emails)                          |
| `logo-icon-on-dark.png` / `.svg`  | Gear "G" alone, on dark. SVG is as supplied (keeps its 1200px canvas margin) |
| `logo-icon-on-light.png` / `.svg` | Gear "G" alone, on light                                                     |
| `og-default.png`                  | Default Open Graph / Twitter image (1200x630), derived from the icon         |

Derived from the icon-only artwork on the brand dark surface: `src/app/favicon.ico` (16/32/48), `src/app/icon.png` (192),
`src/app/apple-icon.png` (180). The `<Logo>` component shows the on-dark or on-light artwork by CSS, following the active theme.
